# indieStream

## Description

An indie music streaming platform built with Next.js, Tailwind CSS, and TypeScript. Discover, stream, and support independent artists.

## Technologies Used

- Next.js
- Tailwind CSS
- TypeScript
- React
- Vercel for deployment
- Neon PostgreSQL for database
